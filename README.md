# FoodShare

## Csapattagok:
- Tábi Ákos
- Soós-Nagy Márk

Az alábbi projekt egy recepetek megosztására és a felhasználó által megadott szempontok szerint véletlenszerű menük generálására való weboldal, a Visual Studio Blazor Web App sablonjából kiindulva a Microsoft Azure segítségével publikálva.

## Munkamegosztás:

Minden lépésnél kisegítettük egymást ha valaki elakadt így mindenki foglalkozott a weboldal minden részével de az alábbiak mindkét csapattag főbb területei:

- Tábi Ákos: Adatbázis és Backend struktúrája, a Menü, Profil és Recept készítése oldalak és ezekhez tartozó backend kérések, mobileszközökre való reszponzivitás.
- Soós Nagy Márk: Weboldal dizájnja, Fő, Receptek, Recept részletei és Recept szerkesztése oldalak és ezekhez tartozó backend kérések, Autentikáció folyamata.
